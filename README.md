### About me

I'm **Yosef Deutsch**, a developer who enjoys turning real-world problems into thoughtfully designed software.

I build products that make everyday tasks easier—whether that's a browser extension that removes repetitive steps, a web application with a clean interface, or a behind-the-scenes automation that connects everything together.

My approach is simple: **useful features, intuitive UX, polished UI, and reliable functionality.** I'm always learning, refining, and looking for a better way to build.

### What I build

| Area | Focus |
| :-- | :-- |
| **Chrome extensions** | Lightweight tools that make browsing and daily workflows more productive. |
| **Websites & web apps** | Responsive interfaces, full-stack applications, and practical online tools. |
| **Automation & bots** | Task automation, scheduled workflows, integrations, and connected systems. |
| **Desktop applications** | Windows utilities and focused software for everyday use. |
| **Google Workspace tools** | Gmail add-ons and tools that fit naturally into existing workflows. |
| **Backend systems** | APIs, Node.js services, data handling, and application infrastructure. |

### Selected work

- **[YDonate](https://ydonate.net)** — An online fundraising and donation platform in development, designed around flexible donation workflows and organizational needs.
- **Ringkey** — A TOTP authenticator project bringing security-code workflows across the web, a browser extension, and phone access.
- **FinishLater** — A browser productivity project built around making it easier to return to tasks at the right time.
- **VoiceType** — A desktop voice-to-text utility for a faster input workflow.

### How I approach a project

**Make it useful.** Start with the actual problem and focus on features that matter.  
**Make it intuitive.** Keep the interface clear, consistent, and easy to navigate.  
**Make it dependable.** Pay attention to details, edge cases, performance, and maintainability.  
**Keep improving.** Test, learn, iterate, and refine.
